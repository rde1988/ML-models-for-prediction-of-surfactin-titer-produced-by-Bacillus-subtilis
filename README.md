# ML-models-for-prediction-of-surfactin-titer-produced-by-Bacillus-subtilis
Python/Jupyter Notebooks associated with the manuscript on machine learning-assisted optimization of surfactin titer produced by Bacillus subtilis strain

## Notebooks

1. MVLSR-Ridge regression model training and validation using nested LOOCV (MVLSR_Ridge.ipynb)
2. SVR model training and validation using nested LOOCV (SVR.ipnyb)
3. RF model training and validation using nested LOOCV (RF.ipnyb)
4. GPR model training and validation using nested LOOCV, optimization of the surfactin titer using a metaheuristic optimizer. Prediction of GPR mean and standard deviation around futuristic sample points (GPR.ipnyb)

## The Python codes associated with this notebook are linked to the research article entitled "Machine Learning Assisted Optimization of Surfactin Titer Produced by Bacillus subtilis MTCC 2423 from Minimum Fermentation Data with Experimental Validation" published in the ACS Omega journal. (DOI: 10.1021/acsomega.6c07721)
